# Ce que j’ai appris pendant le projet Élan Fitness

## HTML
- [ ] Utiliser les balises principales : `header`, `nav`, `main`, `section` et `footer`.
- [ ] Créer des liens entre plusieurs pages.
- [ ] Ajouter des images et du texte alternatif.
- [ ] Créer un formulaire avec des champs et des labels.
- [ ] Utiliser les balises `meta` pour adapter le site aux écrans et décrire les pages.

## CSS
- [ ] Utiliser Flexbox pour organiser les éléments.
- [ ] Utiliser les marges, les espacements et le padding.
- [ ] Personnaliser les couleurs, les polices, les bordures et les ombres.
- [ ] Réutiliser les classes CSS pour garder le même style sur toutes les pages.
- [ ] Ajouter des effets au survol avec `:hover`.
- [ ] Utiliser les media queries pour adapter le site aux petits écrans.
- [ ] Organiser le CSS pour avoir un code propre et facile à comprendre.
